# 电子圣诞树 · Merry Christmas

一个单文件、离线可运行的「电子圣诞树」动画。整棵树由发光粒子编织而成：九条螺旋灯串、针叶绿雾、彩色灯珠、顶端星芒、飘雪与地面暖光，全部由 Canvas 实时绘制，没有任何外部图片、字体或模型请求。

![预览](preview.png)

## 文件

| 文件 | 说明 |

| `index.html` | 主程序，单文件网页版，双击即开 |
| `tree.py` | 终端版，纯标准库，`python tree.py` 运行 |
| `preview.png` | 网页版截图 |

## 运行

直接双击 `index.html`，用任意现代浏览器打开即可（Chrome / Edge / Safari / Firefox）。

也可以起一个本地服务：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## Python 终端版

如果更喜欢原视频里的 Python 氛围，可以运行同目录的 `tree.py`（纯标准库，无需安装依赖）：

```bash
python tree.py
```

它会用 24 位真彩色和半格字符把终端当像素屏，画一棵会旋转、会飘雪的圣诞树。按 `Ctrl+C` 退出。
想直接打印一帧静态画面，用 `python tree.py --once`。

> 建议使用 Windows Terminal、iTerm2 或任意支持真彩色的现代终端；窗口越宽效果越细腻。

## 交互

| 操作 | 效果 |
| --- | --- |
| 自动 | 树缓慢旋转，灯珠呼吸闪烁，雪持续飘落 |
| 拖动 | 旋转 / 俯仰视角，松手后保留惯性 |

| 系统开启“减少动态效果” | 自动旋转与闪烁自动放缓 |

## 实现要点

- **树形**：9 条参数化螺旋线（半径随高度收窄）绕成圆锥；每条线上按 `i % 6` 间隔放大灯珠，形成灯串节奏。
- **体积**：约 2100 个低亮度针叶粒子填充锥体，另加 150 个彩色挂饰，避免树看起来像空灯罩。
- **投影**：手写 3D → 2D 透视投影（绕 Y 轴旋转 + 俯仰 + 焦距），粒子尺寸随景深缩放。
- **辉光**：粒子使用预渲染的径向渐变贴图，`lighter` 叠加；每帧再做一次 1/4 分辨率模糊回叠，得到柔和的泛光。
- **雪**：三层不同速度、大小、透明度的雪花，带正弦横向摆动，出屏后循环。
- **星芒**：四角星 + 十字光线 + 脉冲光晕，树长成后淡入。

## 可调参数

都在 `index.html` 的脚本顶部与 `buildTree()` 里：

- `STRAND_HUES`：九条灯串的主色（HSL 色相）
- `ACCENT_HUES`：穿插彩灯的颜色
- `ORNAMENT_COLORS`：挂饰色板
- `STRANDS / TURNS / PER`：螺旋条数、圈数、每条点数
- `AUTO_SPIN`：自动旋转速度
- `buildSnow()` 中的 `6800`：雪的密度（数值越小雪越多）

## 兼容性

需要支持 Canvas 2D、`filter` 与 `pointer` 事件的浏览器。页面无网络依赖，可直接拷走单独使用。
